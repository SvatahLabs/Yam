Svatah design system · v1
Dark-first with a light theme. IBM Plex Sans for UI, IBM Plex Mono for anything the runtime wrote. Radix primitives beneath every control; our tokens on top. One lavender accent for chrome and focus; five status colours (amber is abort, warn, and unverified) that never appear without a word or a glyph beside them.

Rules the adapters depend on

Every interactive control has an accessible name and a stable id (the desktop adapters bind by them; the snapshot case fails on an unnamed control). Colour never carries meaning alone: every status has a word or a glyph beside it. Density is the default: 13 px text, 28 px controls, 7 px row padding; the inspector is the only place that breathes. Monospace is for what the runtime wrote, sans for what we wrote. The same action has the same name in the palette, the TUI, the SDK, and the CLI.
