# `com.svatah.yam:svatah-yam`

The Java client for the Yam local service, generated from its OpenAPI
description (REQ-SDK-2, LLD §13.8).

```java
GeneratedClient client = new GeneratedClient(url, token);
String project = client.getProject();
String started = client.postRun("{\"flows\":[\"flows/simple.flow\"]}");
client.events().forEach(System.out::println);
```

Answers are the raw body: the client has no JSON dependency, and one added here
would be a dependency every consumer inherits for a value they already have a
parser for. The shapes are `@svatah/yam-schema`'s published JSON Schemas
(REQ-STD-1).

No dependencies, so `javac` alone compiles it — which is what
`scripts/smoke-clients.mjs` does. The Gradle build is for publishing.

`src/main/java/com/svatah/yam/sdk/GeneratedClient.java` is generated by
`node scripts/generate-clients.mjs`; `Smoke.java` is the smoke script T9.3 asks
for and is not part of the published artifact.
