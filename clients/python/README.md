# `svatah-yam` (Python)

The Python client for the Yam local service, generated from its OpenAPI
description (REQ-SDK-2, LLD §13.8).

```python
from svatah_yam import connect

client = connect()                       # YAM_SERVICE_URL / YAM_SERVICE_TOKEN
project = client.get_project()
run = client.post_run({"flows": ["flows/simple.flow"]})

for event in client.events():
    if event["kind"] == "run.summary":
        break
```

No dependencies: `urllib` is enough for a loopback client and a
`text/event-stream` reader.

Auth is the bearer token `yam serve` prints. The SDK never reads a model
credential.

`svatah_yam/generated.py` is generated by `node scripts/generate-clients.mjs`;
everything else in the package is the two things a description cannot state —
where the service is, and how to read its stream.
